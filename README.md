# Frameball

Minimalistyczna strona marki Frameball — materiały meczowe dla zawodników i akademii.

## Uruchomienie

Otwórz `dist/index.html` w przeglądarce. Strona nie wymaga instalowania zależności ani procesu budowania.

## Zmiana kontaktu

Domyślny link kontaktowy znajduje się na początku pliku `dist/script.js` w stałej `CONTACT_URL`. Zmień go, jeśli konto na Instagramie ma inną nazwę niż `frameball.pl`.

## Publikacja

Repozytorium zawiera gotowy katalog `dist` oraz konfigurację statycznego hostingu w `.openai/hosting.json`.
